Step 3 - Validation and Source-of-Truth Model

3.1 Source Tiers

  • Tier A (Authoritative): Official government, intergovernmental, and designated emergency agencies.
  • Tier B (Institutional): Reputable organizations and established operational partners.
  • Tier C (Signal-only): Social/crowdsourced/unofficial reports; treated as unverified until corroborated.

3.2 Status Classification Rules

  • confirmed: supported by Tier A, or by multiple independent high-credibility sources with no unresolved conflict.
  • preliminary: credible early report with partial corroboration or evolving details.
  • unverified: single-source signal, conflicting claims unresolved, or insufficient source quality.

3.3 Conflict Detection Rules

  • Flag discrepancies in casualties, injuries, displaced counts, or affected area.
  • Flag location/time mismatches for the same incident reference.
  • Preserve all claims and link each to source + timestamp for auditability.

3.4 Source-of-Truth Principle

No single source is absolute for all fields. Source-of-truth is field-specific and evidence-weighted, with Tier A precedence and explicit conflict marking.

Step 4 - Why These Sources Are Strong for This Project

  • Authority and trust: The selected stack prioritizes official agencies and internationally recognized institutions, minimizing misinformation risk.
  • Operational relevance: Sources provide real event alerts, situational indicators, and response context aligned to catastrophic crisis workflows.
  • Coverage depth: Combined sources cover seismic, weather, wildfire, humanitarian, and public-health events without over-relying on one domain.
  • Traceability: Each selected source supports citation, timestamping, and provenance, enabling transparent downstream briefing generation.
  • Resilience: The backup/reference strategy ensures continuity when one source is delayed, partial, or temporarily unavailable.
  • Verification-ready: The source mix supports deterministic classification into confirmed, preliminary, and unverified states.

Conclusion: This source strategy is designed for high-integrity crisis intelligence ingestion where accuracy, timeliness, provenance, and conflict transparency are non-negotiable.
